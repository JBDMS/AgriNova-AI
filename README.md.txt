
# AgriNova AI

AgriNova AI is a rice crop health research project focused on
soil and micronutrient information, rice leaf analysis, and
ESP32 sensor-assisted monitoring.

## Project Structure

- app/ — Streamlit dashboard
- notebooks/ — Jupyter notebooks and experiments
- esp32/ — Arduino IDE code
- src/ — Research implementation Python scripts
- docs/ — Agricultural statistics, micronutrient maps, and STCR references

## Main Project Files

- agrinova_streamlit_dashboard_STCR_demo.py
- arduino_live_test.ipynb
- Dynamic_data_solutions.ipynb
- Rice image dataset ZIP (kept outside the repository until checked)

## Running the Dashboard

Open Anaconda Prompt, activate your project environment,
and navigate to the app folder.

Run:

streamlit run agrinova_streamlit_dashboard_STCR_demo.py

## Research Data

The project uses agricultural statistics, micronutrient
information, STCR crop-wise recommendations, rice images,
and ESP32 sensor readings.

## Important Notes

- Check dataset licences before sharing data.
- Do not upload passwords, API keys, private records, or secrets.
- Validate fertilizer calculations using reliable local
  soil-test data and appropriate agronomic guidance.
- Example sensor readings and demo calculations are not
  validated fertilizer recommendations.
